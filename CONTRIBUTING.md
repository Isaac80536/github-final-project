Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for taking the time to contribute! This project thrives on community involvement, and we appreciate your efforts to make it better.

How Can I Contribute?

1. Reporting Bugs

Before creating a bug report, please check existing issues to ensure it has not already been reported. When filing a bug report, please include:

A clear, descriptive title.

Steps to reproduce the behavior.

Expected versus actual behavior.

Relevant logs, error outputs, or screenshots.

Your operating system and environment details (e.g., Python/Node.js version).

2. Suggesting Enhancements & Ideas

We welcome ideas for new features, optimizations, or design adjustments:

Use the issue tracker to propose your idea.

Clearly describe the feature, the problem it solves, and potential use cases.

Provide examples or mockups where applicable.

3. Documentation Improvements

Improving documentation, fixing typos, adding usage examples, or clarifying instructions are just as valuable as code contributions. Feel free to open a pull request directly for documentation edits.

4. Code Contributions (Bug Fixes & Enhancements)

Fork the repository and clone your fork locally.

Create a branch for your work from main:

git checkout -b feature/your-feature-name
# or
git checkout -b fix/issue-description


Make your changes:

Adhere to the existing code style and formatting standards.

Include relevant unit tests for new functionality or bug fixes.

Run tests: Ensure all existing and new tests pass locally before committing.

Commit your changes: Write clear, descriptive commit messages:

git commit -m "Add feature: calculate quarterly compound options"


Push to your fork:

git push origin feature/your-feature-name


Open a Pull Request: Submit your pull request to the main branch of the upstream repository with a description of what you changed and why.

Code of Conduct

Please review our CODE_OF_CONDUCT.md before interacting with this project. By participating, you agree to uphold its terms to ensure a welcoming and inclusive environment for everyone.
